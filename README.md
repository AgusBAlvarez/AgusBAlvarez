### 🛒 Demo Shop
![Status](https://img.shields.io/badge/status-actively_improving-7c3aed?style=flat) ![Type](https://img.shields.io/badge/type-personal-4c1d95?style=flat)

### 🪑 Furniture Configurator and Cut List
![Status](https://img.shields.io/badge/status-in_development-7c3aed?style=flat) ![Type](https://img.shields.io/badge/university-team_project-4c1d95?style=flat) ![Repo](https://img.shields.io/badge/repo-private-374151?style=flat)

Enter the dimensions of a piece of furniture, pick a template and see it in **3D**. If you like the result, the app generates the **cut list**: every piece to cut, with its measurements.

<p align="center">

  <img src="assets/media/cutlist.png" width="320" alt="Generated cut list">

- **My part:** the **cut list** module. The team split the work into components, 3D modeling, cloud and security, and cut list.
- **Stack:** React · TypeScript · React Three Fiber · Drei · React Router · Firebase (Firestore) · Cloudflare
- **How we work:** issues, pull requests and GitHub Actions (CI).
- 🔒 Private repository (team project) · code available on request

### 🚦 EcoRuta
![Status](https://img.shields.io/badge/status-in_development-7c3aed?style=flat) ![Type](https://img.shields.io/badge/university-team_project-4c1d95?style=flat) ![Repo](https://img.shields.io/badge/repo-private-374151?style=flat)
